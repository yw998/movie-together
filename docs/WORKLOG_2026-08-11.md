### Metrograph

- Parses the official in-theater film page.
- Resolves yearless date labels only within the requested window.
- Retains Vista session IDs, 16mm/35mm/70mm/DCP formats, special labels, and
  sold-out sessions without fabricating missing ticket URLs.
- Live verification returned 49 films and 61 showings, including four sold-out

### Paris Theater

- Combines the official digital showtime API with the theater's official CMS.
- Discovers the current public client contract from the theater's layout bundle
  at runtime. Client configuration values are never persisted or logged.
- Joins showtimes to CMS films by Vista film ID and special-event copy by exact
  ticket/showtime ID.
- Live verification for August 11–17 returned two films and 11 showings without
  warnings.

Live counts are point-in-time verification results, not permanent expectations.
Each adapter treats structural changes, missing identifiers, and uncertain
matches as review conditions rather than filling gaps with inferred data.

## Review and approval workflow

- Added comparison of serialized ingestion bundles by stable showing ID.
- Reports list added, removed, and factually changed showings per cinema.
- Publication is held when a feed fails or is partial, warnings exist, IDs are
  duplicated, records are unverified, a cinema is missing or empty, or a
  showing count drops by more than 25 percent.
- A clean report is labeled `READY FOR APPROVAL`, not ready for automatic
  publication.
- Added a named approval command that writes a new audit artifact and refuses
  reports containing concerns. Existing approval files are not overwritten.
- Added a unified weekly candidate command that runs the five implemented
  adapters concurrently and writes a new immutable candidate bundle. It never
  publishes.

Relevant commands:

```text
npm run ingest:week -- YYYY-MM-DD candidate.json
npm run review:schedule -- previous.json candidate.json report.json
npm run approve:schedule -- report.json reviewer approval.json
```
